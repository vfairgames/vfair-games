# Plinko math

Fixed Plinko-style payout tables. Outcome is provably fair; multipliers do not depend on partner RTP configuration.

## How it works

1. **Path** — for each of `rows` pin levels, HMAC produces a float; `≥ 0.5` → right, else left.
2. **Bucket** — `bucketIndex` = number of rights (`0 … rows`).
3. **Payout** — `bet × multiplier[bucketIndex]` from the table for `(rows, risk)`.

Each bounce is treated as fair 50/50, so bucket chance is binomial:

```
P(bucket k) = C(rows, k) / 2^rows
```

Risk only changes multipliers, not chances. Expected return ≈ `Σ(multiplier × P)` (~99% on Plinko tables).

## Limits

|                     |                            |
| ------------------- | -------------------------- |
| Rows                | 8–16                       |
| Risk                | easy, medium, hard, expert |
| Multiplier decimals | 2                          |
