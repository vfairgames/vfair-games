Integrate VFair games into your platform with two server-to-server flows:

1. **Your backend → VFair** — request a game launch URL for a player
2. **VFair → your backend** — read balance and settle bets through your wallet API

Players open the returned game URL (iframe or redirect). The game client talks to VFair directly; you do not proxy gameplay traffic.

## Architecture

```text
Your backend                         VFair API
     │                                    │
     │  POST /api/launch                  │
     │  (partner JWT)                     │
     ├───────────────────────────────────►│
     │◄───────────────────────────────────┤  { url }
     │                                    │
     │  GET  /balance                     │
     │  POST /transaction                 │
     │  (partner JWT)                     │
     │◄───────────────────────────────────┤
     │                                    │
Player browser ── game URL ──────────────►│  game + session
```

## What you need from VFair

Before integrating, VFair provisions your partner account with:

| Item           | Purpose                                       |
| -------------- | --------------------------------------------- |
| Partner code   | Stable identifier used as the JWT `sub` claim |
| Partner secret | Shared secret for signing and verifying JWTs  |
| IP whitelist   | Allowed source IPs for calls to the VFair API |
| Wallet URL     | Base URL of your wallet API (called by VFair) |
| Enabled games  | Game IDs and RTP configured for your account  |
| Currencies     | Allowed currencies and bet limits             |

## Base URL

| Environment | Base URL                                                        |
| ----------- | --------------------------------------------------------------- |
| Production  | Provided by VFair (for example `https://games-api.example.com`) |

All partner API paths are under `/api`.

## Supported games

| Game ID    | Name   |
| ---------- | ------ |
| `v_dice`   | Dice   |
| `v_limbo`  | Limbo  |
| `v_plinko` | Plinko |
| `v_mines`  | Mines  |
| `v_keno`   | Keno   |

## Play modes

| Mode   | Behavior                                                   |
| ------ | ---------------------------------------------------------- |
| `real` | Full session. Balance and bets go through your wallet API. |
| `demo` | Fun play only. No session token and no wallet calls.       |
